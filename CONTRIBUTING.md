# Contributing

## Development

1. Create a virtual environment.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run tests with `pytest`.
4. Keep changes scoped and include tests for behavior changes.

## Quality Bar

- Preserve structured task state and trace fields.
- Add or update tests for retries, fallback, routing, and API behavior.
- Do not commit `.env`, local databases, virtual environments, logs, or caches.
